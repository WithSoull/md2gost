# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What is md2gost

CLI-утилита для конвертации Markdown в DOCX по ГОСТ 7.32 (научные/учебные отчёты). Обёртка над pandoc + pandoc-crossref с Lua-фильтрами для нумерации разделов, таблиц, формул и листингов кода.

## Commands

```bash
# Установка (Homebrew)
brew tap WithSoull/md2gost https://github.com/WithSoull/md2gost && brew install md2gost

# Установка (dev)
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"

# Конвертация
md2gost convert report.md                    # → report.docx
md2gost convert report.md -o out.docx        # кастомный выход
md2gost convert report.md --no-toc           # без оглавления
md2gost convert report.md --no-title-page    # без титульного блока
md2gost convert report.md --no-validate      # без валидации
md2gost convert report.md --paginate         # финальная вёрстка через LibreOffice (extra pagination)
md2gost convert report.md --paginate --keep-order  # без переноса абзацев к рисункам

# Watch-режим (пересобирает при сохранении)
md2gost watch report.md

# Тесты
.venv/bin/pytest tests/ -v
```

Внешние зависимости (должны быть в PATH): `pandoc`, `pandoc-crossref`; для `--paginate` — LibreOffice 7.4+ (`soffice`) и `pypdf`.

## Architecture

**Пайплайн конвертации** (`converter.py`):
1. `validator.py` проверяет .md: YAML-шапка, уровни заголовков, пути картинок, crossref-ссылки, слово «Рисун…»/«Табли…» перед `@fig:`/`@tbl:`, сноски, регистр и пунктуация заголовков, подписей и пунктов списков, запятая после формулы перед «где», тире «–», число источников, ссылки на приложения. Частые нарушения сводятся в одно предупреждение (`_summary()`). Все проверки — предупреждения, текст автора не меняется
2. `build_command()` собирает вызов pandoc с Lua-фильтрами и pandoc-crossref
3. Pandoc генерирует .docx по шаблону `md2gost/templates/gost-7.32.docx` (профиль правил оформления, параметры и согласованные исключения в `analysis/formatting-rules.md`)
4. `formatting.py` нормализует встроенный профиль: стили, поля, колонтитулы, списки, таблицы, поля оглавления и альбомные разделы. `serialize()` вызывает `normalize_order()`: дети `pPr`, `rPr`, `style`, `tblPr`, `tcPr`, `sectPr`, `lvl`, `settings` и др. сортируются по `SCHEMA_ORDER` (Word игнорирует свойства вне порядка схемы, LibreOffice — нет). Таблицы с равными `gridCol`, кроме листингов, получают ширины по содержимому (`fit_columns()`: оценка ширины текста ячеек, включая `m:t`; не уже самого длинного слова; короткая таблица уже текста, широкая = ширине раздела из `section_widths()`), `tcW` в `dxa` и `tblLayout autofit`. Поля ячеек — `CELL_MARGIN_Y`/`CELL_MARGIN_X` (57/108 twips). Формулы остаются OMML с номером справа; интервал до и после — `EQUATION_SPACING` (483 twips = 14 × 1,15 × 1,5 пт, одна строка); формула перед `Where` получает `keepNext`. Стиль `Where` (табуляция `WHERE_TAB` 709), `Appendix Section`, `Bibliography Heading` задаются в `configure_styles()`. С пользовательским шаблоном применяются только `_fix_equations()` и `_fix_keep_with_media()`. Поддерживается `break-after="5,10"` у таблиц и листингов.
5. `--paginate` (`pagination.py`): черновик с закладками у каждого блока и строки таблицы → PDF LibreOffice с именованными назначениями (страница и высота) → исправление самой ранней проблемы (`Document.first_issue()`: деление таблицы/листинга по странице с «Продолжение Таблицы/Листинга N», уменьшение или перенос текста перед рисунком при пустоте ≥ 4 строк) → повтор. Номера оглавления — из закладок `GOSTHeadingN`. Текст PDF не сопоставляется.

**Lua-фильтры** (`md2gost/filters/`):
- `uppercase-h1.lua` — H1 структурные, H2/H3/H4 → Word уровни 1/2/3, главы прописными; глобальная нумерация глав. В приложениях `#` «Приложение А. Название» → обозначение + `Appendix Title`, `##` → «Приложение А.1» (`Appendix Section`) + название, `###` → «А.1.1». Пустая часть «Приложения» получает перечень приложений. `##` в списке источников → `Bibliography Heading`. Переходы на новую страницу задаются стилями, не пустыми абзацами с разрывом.
- `gost-text.lua` — кавычки: «…»/„…“ в русском, “…”/‘…’ в английском.
- `gost-tables.lua` — нумерация таблиц, рисунков и только упомянутых в ссылках формул по главам/приложениям; опережающие и групповые ссылки (`@fig:`/`@tbl:` → только номер, `@eq:` → «(N)»); абзац «где» сразу после формулы разбивается по `SoftBreak` на абзацы `custom-style="Where"` с табуляцией перед каждым обозначением; маркеры `.landscape` для OOXML-постобработки.
- `appendix-listing.lua` — блоки кода с первой строкой «Листинг ...» → подпись `GOSTListingCaption` и таблица-рамка Courier New 10pt, одна строка кода = одна строка таблицы; `.numberLines` — номера с шагом 10; `break-after` — ручное деление.
- `gost-equations.lua` — старый неиспользуемый фильтр; не подключать: он превращает формулу в текст TeX. Рабочее форматирование формул находится в `formatting.py`.

**Порядок фильтров критичен**: Lua-фильтры идут ДО pandoc-crossref в командной строке pandoc.

## Markdown conventions

- YAML-шапка обязательна: `title`, `author`, `date`, `lang: ru`
- `#` (H1) — только ненумерованные: Введение, Заключение, Реферат, Список источников, Приложение X
- `##` / `###` / `####` — нумерованные разделы/подразделы/пункты (номера добавляются Lua-фильтром)
- Рисунки: `![Caption](path){#fig:name}`, ссылки «на Рисунке @fig:name» — слово в нужном падеже с заглавной пишет автор, фильтр подставляет только номер
- Таблицы: `: Caption {#tbl:name}` перед таблицей, ссылки «в Таблице @tbl:name»; для ширины по содержимому оставлять равные дефисы `|---|---|`
- Формулы: `$$ ... $$ {#eq:name}`, ссылки «по формуле @eq:name» → «по формуле (1.1)»; перед «где» формула заканчивается запятой внутри `$$`
- Пояснения после формулы: следующий абзац начинается с «где», каждое обозначение — с новой строки исходника, без пустых строк между ними
- Листинги: блок кода, первая строка `Листинг А.1 — Описание`; `{.numberLines}` для ссылок на строки
- Приложения: `# Приложения` (перечень создаётся сам), `# Приложение А. Название`, разделы `##`
- Абзац со ссылкой на медиа ставится непосредственно ПЕРЕД медиа-элементом
- Не ставить два медиа подряд без текста между ними

## Изменения оформления

Перед изменениями прочитать `analysis/formatting-rules.md`. Таблицы и листинги по согласованию с пользователем не требуют новой страницы; после подписи таблицы 0 пт. Формулы с метками без ссылок не нумеруются. Пояснения «где» поддерживаются и после формул без меток. Оглавление 14 пт/1,5. После правок `configure_styles()` пересобрать стили шаблона: `apply_rules_layout(Path('md2gost/templates/gost-7.32.docx'), template_only=True)`. Синхронизировать код, встроенный шаблон, README, `analysis/formatting-rules.md` и `.claude/commands/write-report.md`. Проверить тесты (`tests/test_pagination.py` с LibreOffice пропускается без `soffice`) и отрендерить диплом с `--paginate`. Не объявлять полное соответствие только по успешной конвертации и не судить о Word по рендеру LibreOffice.
